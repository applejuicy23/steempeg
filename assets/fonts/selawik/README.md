# Selawik

Microsoft’s OFL-licensed Segoe-like UI face. Official binaries from
[microsoft/Selawik](https://github.com/microsoft/Selawik) release **1.01**.

License: `LICENSE.txt` (SIL Open Font License 1.1, Reserved Font Name Selawik).

Steempeg **does not** ship Segoe UI. Selawik install and Settings → UI font
are **Linux-only**. On Windows the app always uses classic Segoe UI from the OS.
On Linux, Steempeg copies these TTFs into the user fonts directory
(`~/.local/share/fonts/steempeg/`) so they are available for the user.
